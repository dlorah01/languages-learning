## How this course works

- Every lesson you receive will come as its own downloadable `.md` file (a "README" for that lesson), numbered in sequence (e.g. `01_Foundations_HowEnglishWorks.md`).
- Each file is self-contained: you can save it, print it, review it later, or drop it into a note-taking app.
- Lessons build on each other. I will explicitly reference earlier lessons ("as we saw in Lesson 3...") so the material accumulates into one connected system instead of a pile of disconnected facts.
- Every lesson follows the same internal template: intuitive explanation → linguistic explanation → why/when/when-not → register & frequency → US/UK notes → Spanish-speaker traps → patterns → examples (easy→hard) → collocations → related expressions → exercises → mini quiz → interview-style Qs → speaking & writing practice.
- I will use spaced repetition on purpose: earlier lessons resurface inside later quizzes, so nothing is "learned once and forgotten."
- You control pacing. At the end of each lesson I'll tell you what's next, but you can jump anywhere, ask for more practice on something, or request a "mixed review" lesson at any time.

## Suggested path

The phases are ordered for a *typical* learner, but nothing is locked. Two good starting strategies:

1. **Sequential** — start at Lesson 1 and move straight through. Best if you want maximum structure.
2. **Diagnostic** — tell me your biggest pain points (you already flagged prepositions), and I reorder the roadmap to hit those earlier, while still eventually covering everything.

Every lesson file will end with a "Recommended Next" note, and you can always say *"give me a mixed review"* or *"go back to prepositions"* at any point.
