# Lesson 48 — Phrasal Verbs with BREAK, TURN and SET
### Phase 4: Phrasal Verbs | Module 5 of 7

---

## 0. Where this fits
Lesson 36 taught SET and BREAK as core verbs; Lesson 35 introduced TURN inside the "become" chart. Lessons 44–47 gave you the tools: the transparency spectrum, separability, and three-part verbs. This lesson applies them to three verbs at once, because they share a theme: **change**.

- **BREAK** = a change of *continuity* (something stops, splits, or begins suddenly).
- **TURN** = a change of *direction or state* (something rotates, becomes, or proves to be).
- **SET** = a change of *position or status* (something is placed, arranged, or begins).

Between them, these verbs produce some of the most multi-meaning phrasal verbs in English: *break down*, *turn out*, *set up*, *turn down*, *break up*. One of the main skills here is **choosing the meaning from context**.

---

## 1. Intuitive Explanation

**BREAK** = a line is cut. The particle tells you what kind of cut.
- break **down** → falls apart (a machine, a person, a calculation)
- break **up** → splits into pieces or ends a relationship
- break **in** → forces entry, or makes something comfortable with use
- break **out** → escapes or suddenly starts
- break **off** → detaches or ends abruptly
- break **through** → passes an obstacle
- break **even** → no profit, no loss

**TURN** = a rotation. The particle tells you where you end up.
- turn **on / off** → switch a device
- turn **up / down** → raise or lower (volume) *or* appear / refuse
- turn **out** → end up, prove to be
- turn **into** → transform
- turn **over** → flip, hand over
- turn **around** → reverse direction
- turn **in** → submit, go to bed

**SET** = something is positioned or started. The particle tells you what for.
- set **up** → establish, arrange
- set **off** → begin a journey, or trigger
- set **out** → begin with an aim, or display
- set **aside** → reserve
- set **back** → delay
- set **down** → place, write
- set **apart** → distinguish

If you can picture a **line being cut** (BREAK), a **knob being rotated** (TURN), or a **piece being placed on a board** (SET), you can predict most meanings.

## 2. The Linguistic Explanation

### 2.1 Families

| Verb | Family | Phrasal verbs |
|---|---|---|
| BREAK | **Stopping / failing** | break **down**, break **off**, break **up**, break **apart** |
| BREAK | **Entering / escaping** | break **in**, break **out**, break **into**, break **away** |
| BREAK | **Progress / interruption** | break **through**, break **in on** |
| TURN | **Switching / adjusting** | turn **on**, turn **off**, turn **up**, turn **down** |
| TURN | **Outcome / transformation** | turn **out**, turn **into**, turn **to** |
| TURN | **Direction / handling** | turn **around**, turn **over**, turn **in**, turn **away**, turn **back** |
| SET | **Establishing / arranging** | set **up**, set **out**, set **aside**, set **about** |
| SET | **Starting / triggering** | set **off**, set **in**, set **on** |
| SET | **Delaying / distinguishing** | set **back**, set **apart**, set **down** |

### 2.2 BREAK — meanings and examples

- **break down** — (1) machine fails: *My car broke down.* (2) person loses control: *She broke down in tears.* (3) analyze into parts: *Let me break down the costs.* (4) negotiations fail: *Talks broke down.*
- **break up** — (1) end a relationship: *They broke up last month.* (2) divide into pieces: *Break up the chocolate.* (3) end a gathering: *The meeting broke up at noon.* (4) signal fails on phone: *You're breaking up.*
- **break in** — (1) enter by force: *Thieves broke in.* (2) wear new shoes until comfortable: *I'm breaking in my boots.* (3) interrupt: *He broke in with a question.*
- **break into** — enter by force; also start suddenly: *They broke into the house.* / *She broke into song.* / *He broke into a sweat.*
- **break out** — (1) escape: *Three prisoners broke out.* (2) begin suddenly: *War broke out.* / *A fire broke out.* (3) get a rash: *I broke out in hives.*
- **break off** — (1) detach: *Part of the handle broke off.* (2) end suddenly: *He broke off the engagement.* / *She broke off mid-sentence.*
- **break through** — pass an obstacle; achieve a discovery: *Scientists made a breakthrough.* / *The sun broke through the clouds.*
- **break away** — leave a group: *A faction broke away from the party.*
- **break even** — neither profit nor lose: *We barely broke even this year.*
- **break up with** (three-part) — end a relationship with someone: *She broke up with her boyfriend.*

### 2.3 TURN — meanings and examples

- **turn on / off** — switch a device (separable): *Turn on the light. / Turn it off.* Also: *That really turns me on / off* (attract/repel, informal).
- **turn up** — (1) increase: *Turn up the volume.* (2) arrive, appear: *He turned up an hour late.* (3) be found: *My keys finally turned up.*
- **turn down** — (1) decrease: *Turn down the music.* (2) refuse: *She turned down the job offer.*
- **turn out** — (1) prove to be / end up: *It turned out (that) he was right.* / *Everything turned out fine.* (2) produce: *The factory turns out 500 cars a day.* (3) attend: *Thousands turned out to vote.* (4) switch off light (UK): *Turn out the light.*
- **turn into** — transform: *The caterpillar turned into a butterfly.* / *The argument turned into a fight.*
- **turn to** — go to for help: *She turned to her mother for advice.* / *Turn to page 10.*
- **turn around** (UK also *round*) — (1) reverse direction: *Turn around!* (2) improve a business: *He turned the company around.* (3) complete a task: *We can turn this around by Friday.*
- **turn over** — flip; hand over; (business) have revenue: *Turn over the page.* / *They turned him over to the police.* / *The firm turns over £2m a year.*
- **turn in** — (1) submit: *Turn in your essay.* (2) go to bed (informal): *I'm going to turn in.* (3) report someone to authorities.
- **turn away** — refuse entry or look away: *The club turned him away.*
- **turn back** — return or reverse: *We had to turn back because of the storm.*

### 2.4 SET — meanings and examples

- **set up** — (1) establish: *They set up a company.* (2) arrange: *Let's set up a meeting.* (3) assemble equipment: *I'll set up the projector.* (4) frame someone: *He was set up by his partner.*
- **set off** — (1) start a journey: *We set off at dawn.* (2) trigger: *The smoke set off the alarm.* / *The remark set him off.*
- **set out** — (1) begin with a goal: *She set out to change the industry.* (2) explain clearly: *The report sets out our objectives.* (3) arrange for display.
- **set about** — begin energetically (inseparable, followed by -ing): *He set about fixing the roof.*
- **set aside** — reserve / ignore: *I set aside time each day.* / *Let's set aside our differences.*
- **set back** — delay or cost: *The storm set us back a week.* / *That car set me back $20,000.*
- **set down** — place; write down (formal); US: let off a passenger: *Set it down on the table.* / *The rules are set down in the contract.*
- **set in** — begin and seem to continue: *Winter has set in.* / *Doubt set in.*
- **set apart** — distinguish: *What sets her apart is her honesty.*
- **set on** — attack (often passive): *They were set on by dogs.* / *She is set on going.* (determined)
- **set free / loose** — not phrasal but similar pattern.

### 2.5 Separability

| Phrasal verb | Type | Notes |
|---|---|---|
| break down (machine) | Intransitive | no object |
| break down (analyze) | Separable | *break the costs down / break them down* |
| break up (relationship) | Intransitive | *They broke up.* |
| break up (divide) | Separable | *break it up* |
| break in (shoes) | Separable | *break them in* |
| break into | **Inseparable** | *break into it* |
| break out | Intransitive | |
| break off | Both | *break it off / The handle broke off.* |
| break through | Intransitive / inseparable | *break through the wall* |
| turn on / off | Separable | *turn it on* |
| turn up / down | Separable | *turn it up* (volume) |
| turn up (arrive) | Intransitive | |
| turn out | Intransitive (mostly) | *It turned out well.* |
| turn into | **Inseparable** | *turn into a frog* |
| turn to | **Inseparable** | *turn to him* |
| turn over | Separable | *turn it over* |
| turn in | Separable | *turn it in* |
| turn around | Both | *turn the company around / It turned around.* |
| set up | Separable | *set it up* |
| set off | Both | *set the alarm off / We set off early.* |
| set out | Both | |
| set about | **Inseparable** | *set about it* |
| set aside | Separable | *set it aside* |
| set back | Separable | *set us back* |
| set apart | Separable | *set her apart* |
| set on | **Inseparable** | *set on him* |

**Rule of thumb:** verbs that move or switch a *thing* are separable (*turn it on, set it up*). Verbs that move *you* or describe events (*break out, turn out, set off on a trip*) are intransitive. Prepositional ones with *into / about / on* are inseparable.

## 3. Why Native Speakers Use Them

| Phrasal (natural) | Formal alternative |
|---|---|
| break down (costs) | itemize, analyze |
| break up with | end a relationship with |
| turn down | decline, reject |
| turn up | arrive, appear |
| turn out | prove, result |
| turn in | submit |
| turn around (a company) | revive, reverse |
| set up | establish, found |
| set off | depart, trigger |
| set out | outline, state |
| set back | delay, hinder |
| set aside | allocate, reserve |
| set apart | distinguish |
| break out | erupt |

A resume might say *"established a new department"* (formal); in an interview, *"I set up a new department"* sounds confident and natural. *"Decline an offer"* works in an email; *"I turned it down"* is how people tell the story.

## 4. When to Use / When Not To
- **Use** *turn out* to describe unexpected outcomes: *It turned out to be a great idea.*
- **Use** *turn down* for refusing offers, applications, and invitations; it is gentler than *reject* and more natural than *refuse*.
- **Use** *set up* in business: *set up a meeting, a company, an account, a system.* It is high-frequency in professional English.
- **Use** *break down* for analysis (*break down the data*) and for emotional collapse; context decides.
- **Don't** confuse *turn down* (refuse) with *turn it down* (lower the volume). The object decides: an offer → refuse; a sound → lower.
- **Don't** say *turn out* + noun for "switch off a device" in American English. Use *turn off*.
- **Don't** use *break up* with a non-couple when you mean *end*: *The meeting broke up* is fine, but *They broke up the contract* is wrong (use *terminated*).
- **Careful:** *set off* and *set out* are close for journeys. *Set off* = begin traveling (focus on leaving). *Set out* = begin with a purpose (focus on aim): *She set out to write a novel.*

## 6. American vs. British Notes
- **turn out the light** (UK, common) vs. **turn off the light** (US).
- **turn around** (US) vs. **turn round** (UK, also *around*).
- **turn up** (arrive) is much more common in UK; US prefers *show up*.
- **turnover**: UK/business = annual revenue; US = *revenue* or *sales*. US *turnover* more often means staff leaving: *employee turnover*.
- **break off** an engagement: universal. **call off** is common in both.
- **set off** a firework / alarm: both; **let off** fireworks is UK.
- **break in** vs. **break-in** (noun): both varieties use the noun for burglary.
- **break a leg** (good luck, theater) is universal.
- **set the table** (US/UK) vs. **lay the table** (UK).
- **Turn in** (go to bed) is more common in older or UK speech.

## 7. Common Mistakes Made by Spanish Speakers

1. **Pronoun placement with separable verbs**
   - ❌ *Turn on it.* / *Set up it.* / *Turn off them.*
   - ✅ *Turn it on.* / *Set it up.* / *Turn them off.*

2. **Using *turn* for *volver*/*ponerse***
   - ❌ *She turned angry.* (acceptable but rare) → ✅ *She got angry.*
   - ❌ *The weather turned out hot* (meaning "became hot") → ✅ *The weather turned hot.* Or *It turned out to be hot.*
   - *Turn* + adjective is used for color and dramatic change (*turn red, turn cold, turn sour*), not for everyday moods. See the become-chart in Lessons 35–36.

3. **Confusing *turn out* with *turn off***
   - ❌ *Turn out the TV* (US: wrong; UK: possible only for lights).
   - ✅ *Turn off the TV.*
   - ✅ *It turned out that he was lying.*

4. **Using *turn out* without *to be* or *that***
   - ❌ *It turned out interesting.* (acceptable informally)
   - ✅ *It turned out to be interesting.* / *It turned out well.* / *It turned out that she was right.*

5. **Wrong preposition in *break up with***
   - ❌ *She broke up to him.* / *She broke up from him.*
   - ✅ *She broke up with him.*

6. **Calling a break-in a *robbery***
   - ❌ *They broke into my house, so it was a robbery.* (Robbery requires force against a person.)
   - ✅ *It was a burglary / break-in.* (nuance: robbery vs burglary)

7. **Using *set up* when Spanish says *poner* or *montar***
   - ❌ *Put a company* → ✅ *Set up / start a company.*
   - ❌ *Mount a meeting* → ✅ *Set up / arrange a meeting.*

8. **Confusing *set off* and *set out* in sentences with infinitives**
   - ❌ *She set off to become a doctor.*
   - ✅ *She set out to become a doctor.* (aim) / *She set off for Madrid.* (journey)

9. **Adding a preposition to *set about***
   - ❌ *He set about to fix the roof.* (acceptable in older English, rare now)
   - ✅ *He set about fixing the roof.* (gerund)

10. **Mispronouncing *break***
    - ❌ /brɛk/ (rhymes with "neck") or /brik/ ("brick")
    - ✅ /breɪk/ (rhymes with *make*, *take*). *Break* and *steak* are exceptions to the *ea* = /iː/ rule.

11. **Mispronouncing *turn***
    - ❌ /turn/ with a rolled r or a pure /u/
    - ✅ /tɜːrn/ (US) or /tɜːn/ (UK): a mid-central vowel with no rolled r.

12. **Using *turn down* for "decrease" of non-sound things**
    - ❌ *We turned down the prices.* → ✅ *We lowered / cut the prices.*

## 8. Common Misconceptions
- ❌ "*Turn down* always means refuse." — With volume, temperature, or lights, it means lower.
- ❌ "*Break down* is only for machines." — It also means analyze, cry uncontrollably, or fail (talks).
- ❌ "*Set up* just means create." — It also means frame someone, or arrange, or assemble.
- ❌ "*Turn out* means switch off." — Only in UK for lights. Otherwise it means prove or produce.
- ❌ "Phrasal verbs are interchangeable." — *Set off* vs *set out* differ in focus; *turn up* vs *show up* differ in region.
- ❌ "*Break up* and *break down* mean the same thing." — *Break up* is dividing or ending (relationship, gathering); *break down* is failing or analyzing.

## 9. Pronunciation Note
1. **BREAK /breɪk/** — long /eɪ/ diphthong, not /ɛ/ or /i/. Rhymes with *take, make, lake*.
2. **TURN /tɜːrn/** — the vowel of *bird, word, learn*. Spanish speakers often substitute /u/ or /e/. Round your lips slightly, keep the tongue central, and curl the tongue for the US "r".
3. **SET /sɛt/** — short /ɛ/, as in *bed*. Not /seɪt/ (which sounds like *sate*).
4. **Particle stress:** *break DOWN, turn OUT, set UP*. The particle carries the main stress.
5. **Noun/adjective stress shift:** the verb stresses the particle; the noun usually stresses the first syllable.

| Verb (particle stressed) | Noun (first syllable stressed) |
|---|---|
| to break DOWN | a BREAKdown |
| to break IN | a BREAK-in |
| to break THROUGH | a BREAKthrough |
| to turn OUT | a TURNout |
| to turn OVER | TURNover |
| to set UP | a SETup |
| to set BACK | a SETback |

6. **Linking:** *turn it on* → /tɜːr nɪ ˈtɒn/ ("tur-ni-ton"). *Set it up* → /sɛ ˈtɪ ˈtʌp/. In fast speech, the /t/ often becomes a flap in US English.
7. **Distinguish the three vowels in "set, sit, seat":** /ɛ/, /ɪ/, /iː/. Practice minimal pairs: *set–sit–seat*, *bed–bid–bead*.

## 10. Memory Technique

### Three pictures
1. **BREAK = crack.** Draw a line and cut it. Each particle is where the cut happens: down (falls), up (splits), out (escapes), in (enters).
2. **TURN = dial.** Draw a dial. Clockwise = up/on, counter-clockwise = down/off. For *turn out*, picture a box that you open to see what is inside (the outcome appears).
3. **SET = board.** A piece is placed (up), pushed out (out), pushed forward (off), or pushed back (back).

### Meaning-by-context rule
For multi-meaning verbs, ask two questions:
1. **What is the object?** (a machine, a person, a cost, a sound)
2. **Is there an object at all?** (intransitive → event; transitive → action)

| Sentence | Object/context | Meaning |
|---|---|---|
| The car broke down. | machine | failed |
| She broke down. | person | cried |
| Let's break down the numbers. | data | analyze |
| Turn down the music. | sound | lower |
| She turned down the offer. | offer | refuse |

### Opposites cement meaning
| Verb | Opposite |
|---|---|
| turn on | turn off |
| turn up | turn down |
| set up | break up / break down |
| set off | set back (move forward vs. delay) |
| break in | break out |
| turn in | turn out (UK) |

### Link back to earlier lessons
| Idea | TAKE | PUT | COME/GO | BREAK/TURN/SET |
|---|---|---|---|---|
| Start | take up | put on | come to | set up / set off |
| End | take down | put out | go under | break up / break off |
| Refuse | take back | put off | go back on | turn down |
| Delay | — | put off | — | set back |
| Prove | — | — | come out | turn out |

### Spaced retrieval

## 11. Patterns (Not Isolated Rules)

> **Pattern 1:** **turn out + to be / that / adjective.** *It turned out to be a mistake. / It turned out that…* This is the standard way to report an unexpected result.

> **Pattern 2:** **set out to + verb.** Standard for stating an aim: *We set out to prove…* This phrase is common in academic and business writing.

> **Pattern 3:** **set about + -ing.** *She set about organizing the files.* Formal-neutral. Compare **go about** + -ing (*How do I go about applying?*).

> **Pattern 4:** **break up with + person.** The three-part form is how you say "end a relationship." Passive/other: *They broke up.* (no "with" needed when both are subject).

> **Pattern 5:** **turn into + noun.** For transformation: *The idea turned into a business.* Compare **turn + adjective** for color/state: *The sky turned dark.*

> **Pattern 6:** **be set on + -ing / noun** (determined): *She is set on becoming a doctor.* Also **be set back** (cost): *The repairs set me back $500.*

> **Pattern 7:** **make a breakthrough / suffer a setback / have a breakdown.** The noun forms are often better in formal writing than the verb forms.

> **Connection to Lesson 36 (SET / BREAK):** *set a goal, set an example, break a record, break a promise* are chunks; the phrasal forms extend them (*set out to meet a goal*).

> **Connection to Lesson 35 (become-chart):** *turn* is the "dramatic change" verb: *turn red / turn cold / turn professional*; compare *get angry* (ordinary), *go mad* (negative), *come true* (positive), *become a doctor* (formal).

> **Connection to Lesson 46 (PUT):** *put off* vs *set back* (both delay, but *put off* is your choice; *set back* is imposed on you). *Put up* vs *set up* (both establish; *set up* is broader and used for organizations).

> **Connection to Lesson 47 (COME/GO):** *come up* (arise) and *turn up* (arrive) are close; *go wrong* and *break down* both express failure.

## 12. Real-Life Examples (Progressively Harder)

**Level 1 — Basic**
- Turn **on** the light.
- Please turn it **off**.
- Set **up** the table.
- The glass broke **apart**.

**Level 2 — Everyday**
- Can you turn **down** the music?
- The car broke **down** on the highway.
- We set **off** at six in the morning.
- He turned **up** late.
- She turned **in** her homework.

**Level 3 — Work and social**
- We **set up** a meeting for Thursday.
- She **turned down** the job offer.
- It **turned out** that the report was wrong.
- They **broke up** after three years.
- The company **broke even** this year.

**Level 4 — Abstract**
- What **sets** her **apart** is her ability to listen.
- The delay **set** us **back** two weeks.
- A fire **broke out** in the warehouse.
- She **set out** to change the system.
- The talks **broke down** over salary.

**Level 5 — Native-like**
- "He **turned** the company **around** in two years, which **set** him **apart** from earlier managers."
- "I **set about** drafting the report, but it **turned out** that half the data was missing."
- "After a long **breakdown** in communication, the two sides **broke through** the impasse."
- "She **turned to** her mentor, who **set** her **straight**."
- "The plan **was set back** by the flood, but it **turned out** better than expected."

**Fixed phrases**
- **turn a blind eye** — ignore deliberately
- **turn over a new leaf** — start fresh
- **turn the tables** — reverse a situation
- **set the record straight** — correct the facts
- **set your heart on** — want very much
- **set in stone** — fixed, unchangeable
- **break the ice** — start conversation
- **break the bank** — cost too much
- **break a sweat** — exert yourself
- **break the news** — tell something important
- **break even** — neither gain nor lose
- **by turns** — alternately

## 13. Collocations & Related Expressions

**Collocations**
- break **down** costs / data / in tears / negotiations
- break **up** with a partner / a fight / a monopoly
- break **out** of prison / a rash / war / fire
- break **in** new shoes / a new employee
- turn **down** an offer / an invitation / a request / the volume
- turn **up** late / at a party / the heat
- turn **out** well / badly / to be a mistake
- turn **into** a disaster / a habit / a business
- set **up** a company / a meeting / a trap / an account
- set **out** a plan / goals / to do something
- set **off** on a trip / an alarm / a chain reaction
- set **back** a project / a schedule / the economy
- set **aside** money / time / differences

**Contrast with similar verbs**
| Idea | Verb | Difference |
|---|---|---|
| Refuse | turn down / decline / reject / refuse | *turn down* is conversational; *decline* polite-formal; *reject* strong |
| Arrive | turn up / show up / arrive | *turn up* implies uncertainty; *arrive* is neutral |
| Start a journey | set off / set out / leave | *set off* = departure moment; *set out* = with a purpose |
| Establish | set up / found / start | *set up* neutral and wide; *found* = long-term institutions |
| Delay | set back / put off / postpone | *set back* imposed; *put off* chosen |
| End a relationship | break up / split up / separate | *split up* similar; *separate* formal or legal |

**Mini Quiz**
1. (a) Machine fails: *The car broke down.* (b) Person cries or collapses: *She broke down in tears.* (c) Analyze: *Break down the costs.* (Also: talks fail.)
2. Same form, different object: an offer, invitation, or request means refuse; a sound, heat, or light means lower.
3. *Set off* focuses on starting a journey or triggering something; *set out* focuses on starting with an aim (*set out to…*) or explaining clearly.
4. Inseparable: *turn into, set about, break into.* Separable: *set up, turn on.*
5. *To be*, *that* clause, or an adjective/adverb (*turned out well*).
6. Because the correct preposition is *with*: *break up with someone*.
7. *Break* /breɪk/ (like *make*); *turn* /tɜːrn/ (vowel of *bird*). Spanish speakers often say /brɛk/ or /brik/, and /turn/ with a pure vowel or rolled r.
8. Verb: stress on the particle (*break DOWN*). Noun: stress on the first syllable (*BREAKdown*).
9. *Set apart* means to distinguish or make different: *What sets her apart is her honesty.*
