# 🇩🇪 German as a Second Native Language

A personal, systematically-built German curriculum for a native Spanish speaker (Colombia) living long-term in Germany, going from A2.2–B1.1 toward full second-native fluency — speaking-first, thinking-in-German focused.

📍 [**Full Roadmap & Progress Log**](00-Roadmap.md) — program structure, phase breakdown, lesson ranges, and completion status.
