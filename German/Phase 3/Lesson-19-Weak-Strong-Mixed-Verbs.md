# Lesson 19 — Weak, Strong, and Mixed Verbs: Why "Irregular" Isn't Random

**Phase:** 3 — Verbs in Depth
**Status:** ✅ Done

---

## 1. The core idea

German "irregular" verbs (sprechen → sprach → gesprochen) aren't random. They follow historical vowel-change patterns called **ablaut**, inherited from an older stage of Germanic (connecting to Lesson 16's history) — once the patterns are visible, memorization gets easier, since you're learning families of verbs, not isolated exceptions.

## 2. Three categories, three logics

**Weak verbs** — the "regular" ones. Past tense with **-te**, past participle with **ge-...-t**; the vowel never changes:
- machen → mach**te** → ge**mach**t
- spielen → spiel**te** → ge**spiel**t
- arbeiten → arbeit**ete** → gearbeit**et** (extra -e- for pronunciation)

**Mental model:** weak verbs are "well-behaved" — the stem stays stable, endings bolt on, like English "walk → walk**ed**."

**Strong verbs** — change their internal vowel (ablaut) for the past tense, often changing again for the past participle, with **ge-...-en**:
- sprechen → **sprach** → ge**sproch**en
- singen → **sang** → ge**sung**en
- fahren → **fuhr** → ge**fahr**en

**Mental model:** strong verbs are "shape-shifters" — the vowel carries the tense information, like English "sing → sang → sung" (the exact same historical ablaut system, inherited by both languages from Proto-Germanic).

**Mixed verbs** — a small closed set combining both strategies: vowel changes like a strong verb, but weak **-te/-t** endings:
- bringen → **brach**te → ge**brach**t
- denken → **dach**te → ge**dach**t
- kennen → **kann**te → ge**kann**t
- wissen → **wuss**te → ge**wuss**t

**Mental model:** hybrids — vowel changes like shape-shifters, endings stay well-behaved. Only ~10 of these total, so genuinely learnable as a finite list, unlike strong verbs (hundreds).

## 3. Connection to Lesson 16's history

Ablaut is a fossil of an ancient Indo-European vowel-alternation system, and English preserves the same mechanism: sing/sang/sung, drink/drank/drunk, speak/spoke/spoken, break/broke/broken. If a strong German verb's English cognate is also irregular in a vowel-shifting way, that's not coincidence — both inherited the same ancient pattern. English intuition (not Spanish, which follows entirely different stem-change logic tied to stress) often predicts which German verbs are likely to be strong.

## 4. Common ablaut patterns worth recognizing as families

| Pattern | Examples |
|---|---|
| ei → i/ie → i/ie | bleiben/blieb/geblieben, schreiben/schrieb/geschrieben |
| e → a → o | sprechen/sprach/gesprochen, helfen/half/geholfen |
| i → a → u | singen/sang/gesungen, trinken/trank/getrunken |
| a → u → a | fahren/fuhr/gefahren, tragen/trug/getragen |

No need to memorize pattern names — just notice whether a new strong verb "rhymes" with a known pattern. Active pattern recognition compounds over time.

## 5. Progressively harder examples

1. Ich habe gestern viel gearbeitet. (weak verb, Perfekt tense — preview of next lesson)
2. Ich habe mit meinem Chef gesprochen, weil ich eine Frage hatte. (strong verb + weil + weak "hatte" — haben's past tense is irregular too)
3. Ich wusste nicht, dass du das schon kanntest. (two mixed verbs + dass)
4. Er hat mir das Buch gebracht, das er mir versprochen hatte. (mixed + strong, participle stacking — advanced, just exposure for now)

## 6. Speaking exercise

Produce the correct forms out loud:
- sprechen → ich ___ gestern mit ihr. (sprach)
- kennen → ich ___ ihn schon lange. (kannte)
- fahren → wir ___ letztes Jahr nach Italien. (fuhren)

Then produce one true sentence about yesterday using a strong verb, and one using a mixed verb.

## 7. Thinking-in-German habit

Narrate one thing done yesterday using a strong or mixed verb, consciously noticing the vowel change:
> *Gestern habe ich mit meiner Familie gesprochen. Ich wusste nicht, dass sie mich anrufen würden.*

(Don't worry about "würden" yet — Konjunktiv II comes later in Phase 3.)

## 8. Real-life mission

Tell someone (or narrate aloud) something done yesterday using at least one strong verb — "Ich habe mit meinem Nachbarn gesprochen" or "Ich bin nach Berlin gefahren" — noticing the vowel retrieval happening in real time.
