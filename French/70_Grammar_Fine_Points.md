# Lesson 70 — Grammar Fine Points: Participle Agreement, Tricky Spellings, and Orthography
### Phase 5: Mastery & Maintenance (C1 → C2+)

**Competency axes trained:** 🧩 Morphosyntax (primary) · ✍️ Writing accuracy · 📖 Reading
**Prerequisite:** Lesson 12 (passé composé), Lesson 24 (object pronouns), Lesson 23 (reflexive verbs), Lesson 64 (writing)
**Time investment:** One read, then a weekly 15-minute proofreading drill.

---

## 1. Why These Details Matter (Intuitive Explanation)

French spelling is famously difficult, and **many native speakers make errors** in the points of this lesson. Mastering them is a mark of educated writing. Importantly, **most of these errors are invisible in speech**: *il mange / ils mangent*, *j'ai mangé / manger*, *a / à* sound identical. This is why the written code has so many "silent" rules.

The good news: nearly every rule here reduces to **a test you can apply mechanically**. You do not need to "feel" it; you need a procedure. That suits your analytical, systems-oriented style.

## 2. Past Participle Agreement: The Master Rules

### 2.1 With *être*: agree with the subject
- *Elle est **partie**.* *Ils sont **arrivés**.* *Elles sont **nées** en mars.*
- Passive voice follows the same rule: *Les lettres ont été **envoyées**.*

### 2.2 With *avoir*: agree with the **direct object only if it comes BEFORE the verb**

**Test (3 questions):**
1. What is the direct object (COD)?
2. Is it **before** the auxiliary verb?
3. If yes, the participle agrees in gender and number with it.

| Sentence | Analysis |
|---|---|
| J'ai acheté **des fleurs**. | COD after the verb → no agreement |
| **Les fleurs** que j'ai achet**ées** | COD (*que* = *les fleurs*) before → agreement |
| Je **les** ai vu**es**. | COD pronoun before (*les* = feminine plural) → agreement |
| **Quelle voiture** as-tu choisi**e** ? | COD (*quelle voiture*) before → agreement |
| Elle **l'**a pris**e**. | *l'* = *la* (feminine) → agreement |

### 2.3 No agreement in these cases
| Case | Example | Reason |
|---|---|---|
| **Indirect object** (COI) | *Je **leur** ai parlé.* | *parler à* → COI, no agreement |
| **Pronoun *en*** | *J'**en** ai mangé.* / *Des pommes, j'en ai acheté.* | *en* never triggers agreement |
| **Intransitive verbs with *avoir*** | *Elles ont **dormi**.* *Ils ont **ri**.* | no object |
| **Impersonal verbs** | *Les chaleurs qu'il a **fait** cet été.* | invariable |
| **Weights, durations, prices (complements)** | *Les deux heures qu'il a **dormi**.* / *Les 80 kilos qu'il a **pesé**.* | quantity, not object |

> **Careful:** *Les efforts que ça m'a **coûté*** (cost, quantity) vs. *Les efforts que ça m'a **coûtés*** (when *coûter* is used figuratively with a true object). Many stylists accept both; the usual advice is "invariable for the price, agreement for the metaphorical 'effort'."

### 2.4 With *faire* and *laisser* + infinitive
- **Faire + infinitive:** *fait* is **always invariable**: *Les enfants qu'elle a **fait** venir.*
- **Laisser + infinitive:** since the 1990 reform, agreement is **optional**: *Les enfants qu'elle a **laissé(s)** partir.*

### 2.5 Perception verbs + infinitive (*voir, entendre, regarder, sentir...*)
Test: **who performs the infinitive's action?**
- *Les chanteuses que j'ai **entendues** chanter.* (the singers sing; COD of *entendre*; agreement)
- *La chanson que j'ai **entendu** chanter.* (the song does not sing; it is the COD of *chanter*; no agreement)

### 2.6 Pronominal (reflexive) verbs
| Type | Rule | Example |
|---|---|---|
| **Reflexive, pronoun = COD** | agrees with the subject | *Elle s'est **lavée**.* |
| **Reflexive, pronoun = COI** | no agreement | *Elles se sont **parlé**.* / *Ils se sont **téléphoné**.* |
| **Reflexive with a COD after the verb** | no agreement (COD is after) | *Elle s'est **lavé** les mains.* |
| **Essentially pronominal** (verb only exists pronominal) | agrees with the subject | *Elle s'est **évanouie**.* *Ils se sont **souvenus**.* |
| **Passive-meaning pronominals** | agrees with the subject | *Ces fleurs se sont bien **vendues**.* |

**Test for COI:** if the verb takes *à* + person (*parler à, téléphoner à, sourire à, plaire à, nuire à*), the *se* is a COI, so no agreement.

### 2.7 Verbs that take either *être* or *avoir*
*Passer, sortir, monter, descendre, rentrer, retourner* take *être* when intransitive and *avoir* when they have a direct object:
- *Elle est **sortie**.* / *Elle a **sorti** la voiture.*
- *Il est **monté**.* / *Il a **monté** l'escalier.*

## 3. The Big Homophone Table (Self-Testing Replacements)

For each pair, apply the **replacement test** in the right column.

| Homophones | Test | Examples |
|---|---|---|
| **a / à** | *a* = *avait*? | Il **a** faim (il avait faim ✔). Il va **à** Paris. |
| **ou / où** | *où* = place/time; *ou* = *ou bien* | Tu veux du thé **ou** du café ? / **Où** vas-tu ? |
| **et / est** | *est* = *était* | Il **est** là **et** il rit. |
| **son / sont** | *sont* = *étaient* | Ils **sont** ici avec **son** frère. |
| **ce / se** | *se* only with verbs (reflexive) | **Ce** livre ; il **se** lève. |
| **ces / ses / c'est / s'est / sait / sais** | *ces* = *ceux-là*; *ses* = *les siens*; *c'est* = *cela est*; *s'est* + participle; *sait* = *il sait*; *sais* = *je sais* | **Ces** gens ; **ses** amis ; **C'est** bon ; il **s'est** levé ; il **sait** |
| **leur / leurs** | *leur* before verb = invariable; before noun, agrees | Je **leur** parle. / **Leurs** amis arrivent. |
| **quel / qu'elle** | *qu'elle* = *que elle* (replace with *qu'il*) | **Quel** livre ? / Je pense **qu'elle** vient. |
| **quelque / quel(s) que** | *quelque* = some/about; *quel que* + subjunctive *être* | **Quelque** chose / **Quelle que** soit la raison |
| **ni / n'y** | *n'y* = *ne + y* | Je **n'y** vais pas. / **Ni** lui **ni** elle. |
| **la / là / l'a** | *l'a* = *l'avait*; *là* = place | **La** table ; il est **là** ; il **l'a** vue |
| **on / on n' / ont** | *ont* = *avaient* | **On** part ; **on n'**a pas vu ; elles **ont** fini |
| **mais / mes / met / mets** | | **Mais** non ; **mes** amis ; il **met** ; je **mets** |
| **peu / peut / peux** | *peut* = *pouvait* | **Peu** de gens ; il **peut** venir |
| **tout / tous / toute / toutes** | *tous* pronounced [tus] as pronoun, [tu] as adjective | **Tous** [tus] sont là ; **tous** [tu] les jours |
| **près / prêt** | *prêt* = ready | Il habite **près** d'ici. Il est **prêt**. |
| **plutôt / plus tôt** | *plus tôt* ≠ *plus tard* | Viens **plus tôt**. Il est **plutôt** gentil. |
| **davantage / d'avantage** | *davantage* = more (adverb) | Il travaille **davantage**. |
| **quand / quant (à) / qu'en** | *quant à* = as for | **Quant à** moi... |
| **quoique / quoi que** | one word = although; two = whatever | **Quoique** fatigué... / **Quoi que** tu dises... |
| **sans / s'en / sang / cent** | | **Sans** toi ; il **s'en** va ; **sang** ; **cent** euros |
| **ça / sa** | *sa* = *la sienne* | **Ça** va ; **sa** voiture |
| **m'a / ma ; t'a / ta** | *m'a* = *m'avait* | Il **m'a** vu ; **ma** sœur |

## 4. Infinitive vs. Participle: -er or -é ?

**Test:** replace the verb with a **third-group verb** (*vendre/vendu*, *prendre/pris*, *mordre/mordu*).

- *Il va (manger/mangé)?* → *Il va **vendre**?* ✔ → **manger**.
- *Il a (manger/mangé)?* → *Il a **vendu**?* ✔ → **mangé**.
- *Le chat (pris/prendre)...* If *vendu* fits → participle (*mangé*).

Also: *après* + infinitive passé (*après avoir mangé*), *pour/sans/de/à* + infinitive (*pour manger*).

## 5. Accents and Diacritics

| Mark | Sound/function | Examples |
|---|---|---|
| **Accent aigu (´)** | [e] | été, café |
| **Accent grave (`)** | [ɛ] on *e*; differentiates *a/à, ou/où, la/là* | père, où |
| **Accent circonflexe (^)** | often marks a **lost *s*** (etymology); long vowel | forêt (*forest*), fête (*feast*), hôpital (*hospital*), île (*isle*), bête (*beast*) |
| **Tréma (¨)** | pronounce separately | Noël, naïf, maïs, aiguë |
| **Cédille (ç)** | [s] before *a, o, u* | français, garçon, reçu |

**Bridge with Spanish:** the circumflex often reveals Spanish cognates: *forêt/foresta*, *fête/fiesta*, *hôpital/hospital*, *île/isla*, *bête/bestia*, *maître/maestro*, *côte/costa*. The lost *s* is still in Spanish.

**Capitals keep accents:** *À bientôt, École, État*. Typing tips: Alt codes or a French keyboard layout (AZERTY or the international layout).

### The 1990 spelling reform (*rectifications orthographiques*)
Recommended since 1990, accepted alongside the traditional spelling:
- The **circumflex on *i* and *u*** may be dropped when it does not distinguish meaning: *maitre*, *connaitre*, *cout* (but keep *sûr*, *mûr*, *dû*, where it matters).
- Some hyphenated numbers: *vingt-et-un* (all numbers hyphenated).
- Simplified words: *oignon → ognon*, *nénuphar → nénufar*.
- Compound plurals made regular: *un pèse-personne → des pèse-personnes*.

**Advice:** both spellings are correct; be consistent. Most publishers and schools still use the traditional forms.

## 6. Plurals, Numbers, and Other Traps

### Plural nouns
| Rule | Examples |
|---|---|
| **Add -s** | un livre → des livres |
| **-al → -aux** | un cheval → des chevaux; un journal → des journaux (exceptions: bals, carnavals, festivals, récitals) |
| **-eau, -eu → -x** | un bateau → des bateaux; un jeu → des jeux |
| **-ou → -s** (seven exceptions take -x) | un trou → des trous; bijoux, cailloux, choux, genoux, hiboux, joujoux, poux |
| **-s, -x, -z unchanged** | un fils → des fils; un nez → des nez |
| **-ail → -s** (some -aux) | un détail → des détails; un travail → des travaux; un vitrail → des vitraux |

### Compound words
Check a dictionary. *Des grands-mères* (modern: *grands-mères*), *des porte-clés / des porte-clefs*.

### Number agreement
- **vingt, cent:** take **-s** only when multiplied and not followed by another number: *quatre-vingts* but *quatre-vingt-un*; *deux cents* but *deux cent un*; *deux cent mille*.
- **mille:** always invariable: *trois mille*.
- **million, milliard:** nouns, take -s: *trois millions d'euros*.

### Adjective traps
- **Colors from nouns** are invariable: *des yeux marron, des chemises orange* (but *rose, mauve, pourpre, écarlate* agree).
- **Compound colors** invariable: *des yeux bleu clair*.
- ***Tout*:** adjective, adverb, or pronoun. As an adverb ("completely"), it is invariable, **except** before a feminine adjective beginning with a consonant or *h aspiré*, where it agrees: *Elle est **toute** petite*, *elle est **toute** honteuse*, but *Elle est **tout** étonnée*, *ils sont **tout** petits*.
- ***Même*:** after the noun it can agree (*les dieux **mêmes***, "the gods themselves"); before it, determiner (*les **mêmes** erreurs*).

## 7. A Reliable Proofreading Method

Proofreading is a **separate task** from writing. Do it in passes, each with a single focus.

| Pass | Focus | Technique |
|---|---|---|
| **1. Verbs** | find each verb and **its subject** | underline subject → verb; check endings (*ils mangent*), tense, mood |
| **2. Participles** | every past participle | apply the 3-question COD test (Section 2) |
| **3. Homophones** | every *a/à, ou/où, ce/se, son/sont, leur/leurs, quel/qu'elle, ses/ces* | use replacement tests (Section 3) |
| **4. Agreement** | noun-adjective-determiner | check gender and number chain |
| **5. Accents/punctuation** | accents, hyphens, spacing | check typography (Lesson 64) |
| **6. Read aloud / backwards** | catch typos | read the text backwards, sentence by sentence |

### Tools (use as a second pair of eyes, not a crutch)
- **Dictionaries:** *Le Robert*, *Larousse*, *Dictionnaire de l'Académie française*, *CNRTL*, *Wiktionnaire*.
- **Grammar references:** *Le Bon Usage* (Grevisse), *Bescherelle* (conjugation), *Banque de dépannage linguistique* (Québec's OQLF, very clear).
- **Correctors:** *Antidote*, *LanguageTool*, *Bon Patron* (free, explains errors).
- **Certification:** the **Certificat Voltaire** (spelling) and **Projet Voltaire** (training) are well known in France.

**Key rule:** when the tool corrects something, **ask why**, then log the error in your error journal (Lesson 62).

## 8. Mental Model: Silent Rules as Hidden Wiring

Imagine written French as a machine with hidden wires: the audible words you hear on the surface, and an extensive system of silent connections (agreement, mood, participle logic) wiring them together underneath. Speech hides the wiring; writing must show it. Each test in this lesson is a **continuity tester**: put the probe on the wire (replace *a* by *avait*, find the COD), and the answer lights up.

## 9. Common Mistakes

**Spanish speakers:**
- Forgetting participle agreement because Spanish does not have it in compound tenses (*he comprado las flores*, invariable); this is the main new rule.
- Mixing *a/à*, *ou/où*, *et/est* (Spanish has *a/ha*, but the distinction differs).
- Spelling with Spanish patterns (*ejemplo → exemple*, *profesor → professeur*, *dificil → difficile*): double consonants (*appeler, apparaître*) and silent letters.
- Over-accenting or under-accenting.

**English speakers:**
- Omitting accents; mixing *é/è*.
- English-style doubling (*comme → comme*, *adresse*) and false cognates in spelling (*address → adresse*, *occasion → occasion*, *necessary → nécessaire*).
- Forgetting agreement of adjectives in the plural and feminine forms.

**Both:** dropping the final *-s* in verb forms (*tu manges*), confusing *-er* and *-é*, forgetting silent endings (*ils chantent*), trusting a spellchecker blindly.

## 10. Progressively Harder Practice

1. **Participle drill (10 sentences):** decide whether each participle agrees and explain with the 3-question test.
2. **Homophone drill:** write 10 sentences, each using a different pair from Section 3, then swap them with replacement tests.
3. **Dictée (dictation):** listen to a 60-second RFI *Journal en français facile* excerpt (with transcript available) and type it. Compare and classify errors (spelling, agreement, homophones).
4. **Proofread a real text:** take an email you wrote last month and apply the six-pass method. Count the errors per pass.
5. **Trap sentences:** correct the participles: *Les lettres qu'il m'a écrit.* / *Elle s'est lavé.* / *Les fleurs qu'elle a acheté.* / *Ils se sont parlés.*
6. **Weekly routine:** pick one rule from this lesson each week, find three examples in real reading, and use it in your writing.
