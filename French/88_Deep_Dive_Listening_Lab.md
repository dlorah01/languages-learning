**Prerequisites:** Lesson 5 (liaison), Lesson 45 (listening at native speed), Lesson 56 (immersion ladder), Lesson 59 (prosody), Lesson 63 (Francophone variation)
**Time investment:** One read, then a four-week deep-dive cycle (Lesson 80, Section 7).

---

## 1. Why Listening Is Still Hard at C1

By now you read well, but real conversation can still slip away. The reason is not vocabulary alone. Spoken French differs from written French in **sound**, **grammar**, and **speed**, and your ear must learn to **reconstruct** the written form from a compressed signal.

**Mental model: listening is prediction plus decoding.** Native listeners predict most of what comes next from context and grammar, and use sound only to confirm. Your job is to build both skills: **faster decoding** (sound → words) and **better prediction** (context → expected words).

| Layer | What breaks down | Training |
|---|---|---|
| **Signal** | speed, reduction, overlaps, noise | slowed practice, dictation, shadowing |
| **Segmentation** | where words begin and end (liaison, enchaînement, no stress) | transcription, minimal pairs |
| **Lexicon** | unknown words and slang | intensive listening + logs |
| **Grammar** | dropped *ne*, dislocation, ellipsis | pattern awareness |
| **Pragmatics** | irony, implicit meaning, fillers | repeated exposure, context notes |

## 2. Reduction: What Spoken French Does to Words

Spoken French shortens frequent word groups. Learn these as **sound units**, not as misspelled words.

### 2.1 Common reductions (informal speech)
| Written | Often heard as | Notes |
|---|---|---|
| *je suis* | *[ʃɥi]* ("chui") | *je* + *s* merge |
| *je ne sais pas* | *[ʃepa]* ("j'sais pas" / "chais pas") | *ne* dropped, *je sais* → *chais* |
| *il y a* | *[ja]* ("y'a") | very frequent |
| *tu as* | *[ta]* ("t'as") | |
| *tu es* | *[ty]* / *[t]* ("t'es") | |
| *ce que / ce qui* | *[skə] / [ski]* ("c'que / c'qui") | |
| *puis* | *[pɥi]* → "pi" | informal |
| *peut-être* | *[ptɛtʁ]* ("p't-être") | |
| *voilà* | *[vwala]* → "v'là" | |
| *quelqu'un* | *[kɛlkœ̃]* ("quèqu'un") | |
| *est-ce que* | *[ɛs(kə)]* → "'sque" | |
| *monsieur* | *[məsjø]* → "m'sieur" | |
| *on va* | *[ɔ̃va]* | liaison-free, but fast |
| *je vais* | *[ʒvɛ]* / *[ʃvɛ]* | |

### 2.2 Systematic processes
| Process | Description | Example |
|---|---|---|
| **Schwa deletion** | the mute *e* drops when it can | *je te le dis* → *[ʒtəldi]* |
| **Assimilation** | neighbouring consonants share voicing | *je suis* → *[ʃɥi]* (voiced → voiceless) |
| **Consonant-cluster simplification** | final clusters are shortened | *table* → *[tab]*, *quatre* → *[kat]* in fast speech |
| **Ne-dropping** | the first part of negation disappears | *Je comprends pas.* |
| **Ellipsis** | missing subject pronoun or verb in fast chains | *Faut y aller.* (= Il faut y aller.) |
| **Contraction of fillers** | *du coup* → *[dyku]* | |

> **Key principle:** these are not errors; they are the **normal spoken standard** among native speakers in informal contexts. Aim to *recognize* them all and to *produce* the light ones (dropped *ne*, *y'a*, *t'as*) when the register fits (Lesson 47).

## 3. Segmentation Problems: Where Does the Word Start?

French has **no lexical stress** and uses **liaison** and **enchaînement**, so the boundaries of words are not marked.

| Written | Heard as | Ambiguity |
|---|---|---|
| *un ami* / *une amie* | *[œ̃nami]* / *[ynami]* | the gender is carried only by the first vowel (nasal vs. [y]) |
| *les élèves* | *[lezelɛv]* | the liaison [z] attaches to the next word and sounds like part of it |
| *l'amour* | *[lamuʁ]* | elision merges article and noun; compare *la mouette* [lamwɛt] |
| *c'est lui* / *s'est lui…* | *[sɛlɥi]* | spelling distinction only; context decides |
| *l'été* / *les thés* / *les États* | [lete] / [le te] / [lezeta] | a single vowel or a liaison [z] separates them |
| *des oiseaux* / *des zoiseaux* (non-standard) | [dezwazo] | the liaison [z] can be misheard as part of the noun, a common learner and child error |

**Minimal-pair cases to train:** *les enfants / les en-fants* (liaison [z]); *un hôtel / un autel*; *ils ont / ils sont* ([ilzɔ̃] both with liaison but different first sounds: *ont* [ɔ̃], *sont* [sɔ̃]).

## 4. Grammar in Real Speech

Spoken French has its own syntax. Expect:

| Feature | Example |
|---|---|
| **Dislocation** | *Moi, je pense que…; Ça, c'est vrai.* |
| **Dropped *ne*** | *Je sais pas.* |
| **Question by intonation** | *Tu viens ?* |
| **Cleft constructions** | *C'est moi qui…; Ce qu'il faut, c'est…* |
| **Repetition and false starts** | *Je… enfin, je pense… je pense que…* |
| **Fillers** | *euh, ben, bah, bref, genre, du coup, en fait, quoi* (Lesson 41) |
| **Tag questions** | *n'est-ce pas ? / non ? / hein ?* |
| **Interruptions and overlaps** | two speakers finishing each other's sentences |
| **Incomplete sentences** | *Si seulement…* |

**Tip:** do not "correct" these in your head. Treat the interrupted, repetitive structure as the **expected pattern** of conversation.

## 5. Accents and Varieties

You do not have to produce every accent, but you must **recognize** the main ones (Lesson 63).

| Variety | Common cues |
|---|---|
| **Standard (Paris/media)** | reference for broadcasts |
| **Southern France (*le Midi*)** | pronounced mute *e* (*une petite fille* with audible schwas), more open vowels, nasal vowels with a trailing consonant |
| **Quebec** | affrication (*t/d* before *i/u* → [ts]/[dz]: *tu* sounds like "tsu"), diphthongization of long vowels, different vocabulary and many English-origin and archaic words |
| **Belgium** | *septante, nonante*, intonation patterns, distinct vocabulary |
| **Switzerland** | *septante, huitante, nonante*, slower rhythm, particular expressions |
| **West and Central Africa** | syllable-timed rhythm, varied intonation, local lexicon, strong variety between countries |
| **Banlieue/youth speech** | verlan, rapid delivery, slang, borrowings |

**Method:** assign one variety per week to your listening diet. Use one reference speaker of each (a radio host, an actor, a comedian) so the accent becomes familiar before you meet it unprepared.

## 6. Training Methods

### 6.1 Intensive listening (short, deep)
Choose **1–3 minutes** of authentic audio and work in this cycle:
1. **Listen blind** (no text). Write what you understand.
2. **Listen in chunks.** Replay each sentence 3–5 times; transcribe (dictation).
3. **Check** with subtitles or a transcript. Mark every error and classify it (segmentation? reduction? unknown word? grammar?).
4. **Shadow:** speak along at the same speed and rhythm, copying intonation.
5. **Re-listen the next day** without text: note improvement.

### 6.2 Extensive listening (long, light)
Listen for **volume**, with a focus on meaning rather than detail: podcasts during commutes, series in the evening. Rule of thumb: aim for material where you understand about **80–90 percent**; below that, switch to intensive work; above 95 percent, raise the difficulty.

### 6.3 Shadowing
Repeat what you hear **almost simultaneously** (0.5–1 second behind). Benefits: trains rhythm, reduction, intonation, and working memory. Start with slow speech; progress to natural speed. Record yourself and compare.

### 6.4 Dictation (*dictée*)
Transcribe short fragments. It reveals what you *think* you hear versus what is said. Count your errors per 100 words and track it weekly.

### 6.5 Subtitle policy
| Stage | Subtitles |
|---|---|
| **Learning new material** | French subtitles (not your native language) |
| **Reviewing** | no subtitles |
| **Avoid** | Spanish or English subtitles most of the time (they let you skip listening) |

### 6.6 Slow-down and loop tools
Players and browser extensions that allow speed control and sentence looping help intensive listening. Check which tools are available for the platform you use.

## 8. Spoken Corpora: Real Data for Analytical Learners

A **corpus** (*corpus oral*) is a collection of recorded and transcribed speech used by linguists. For an analytical learner it is a goldmine: authentic, transcribed, and often free.

| Corpus type | What it offers |
|---|---|
| **Interview and conversation corpora** | transcribed sociolinguistic interviews and conversations |
| **Treebank/prosody corpora** | syntax and intonation annotations |
| **Regional corpora** | speech from Belgium, Switzerland, Quebec, Africa |

Examples of research corpora of spoken French (availability and access conditions vary, so check the project pages): **ESLO** (Orléans sociolinguistic interviews), **Rhapsodie** (prosody and syntax), **ORFÉO** (a large collection of spoken French), **CFPP2000** (Paris speech), **Valibel** (Belgian French). Also look for **transcribed radio archives** and **subtitles** from series and films you own.

**How to use them as a learner**
1. Search for a word or expression (*du coup, genre, ben*) and read 20 real contexts.
2. Notice **what precedes and follows** (collocations), **the intonation**, and **whether it's turn-initial or turn-final**.
3. Add 5 new examples to your notes.

This is the same method as Lesson 49 (collocations), applied to speech.

## 9. The Weekly Listening System

| Day | Activity | Time |
|---|---|---|
| **Mon** | intensive: 2 minutes of news audio, dictation + shadowing | 25 min |
| **Tue** | extensive: podcast or series episode | 30–45 min |
| **Wed** | intensive: 2 minutes of conversational audio (interview or series) | 25 min |
| **Thu** | extensive: radio or documentary | 30 min |
| **Fri** | accent day: a different variety (Quebec, Belgium, Africa, Midi) | 30 min |
| **Sat** | free: film or stand-up for pleasure, French subtitles | 60–120 min |
| **Sun** | review: re-listen to Monday and Wednesday clips without text; update the error log | 20 min |

**Error log columns:** date | source | what I heard | what was said | cause (segmentation / reduction / unknown word / grammar / speed) | fix.

**Progress metric:** every four weeks, retest the same 2-minute clip and record how many words you missed. Your error count is your most honest measure.

## 10. Common Mistakes

**Spanish speakers:**
- Listening for **stressed syllables** as in Spanish; French has phrase-final prominence, not word stress.
- Expecting every word to be clearly separated.
- Confusing French vowels that Spanish merges (*u/ou*, *é/è*, *eu/œ*, *an/on*) and so mishearing words (Lessons 1, 4).
- Hearing *je* + verb as one sound and losing the pronoun.

**English speakers:**
- Over-relying on consonants and stress, which are less informative in French.
- Missing nasal vowels.

**Both:**
- Using subtitles in your native language and skipping the work.
- Always listening to **comfortable** material and never to hard material.
- Not reviewing: listening once without re-listening yields little retention.
- Stopping to look up every word, breaking the flow in extensive listening.

## 12. Progressively Harder Practice

1. **Reduction decoding (10 min):** write the full form for: *chuis pas sûr, y'a pas de souci, t'as vu ça, c'qu'il dit, p't'êt qu'il vient*.
2. **Segmentation:** say aloud and record: *les enfants ont ouvert un atelier*; listen for liaisons and enchaînements.
3. **Dictation:** transcribe a 30-second clip, then compare.
4. **Shadowing:** shadow a 60-second interview twice; record and compare.
5. **Accent day:** listen to two speakers of different varieties talking about the same topic; list three audible differences.
6. **Corpus mini-study:** look up *du coup* in 20 contexts; write a rule of use in French.
7. **Retell:** listen to a 3-minute podcast excerpt and summarize it aloud in French without notes.
